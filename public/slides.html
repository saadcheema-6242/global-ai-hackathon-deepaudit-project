The Problem

LLMs sound confident — even when they are wrong

✕
Hallucinated facts

Statements that sound real but are completely fabricated.

!
Outdated information

Deprecated APIs, superseded events, and stale numbers.

?
Unverifiable claims

Assertions with no authoritative source behind them.

Why existing tools miss it

Spell-checkers, linters, and unit tests catch syntax and logic — not semantic inaccuracy. Manual fact-checking is slow and does not scale. DeepAudit automates that loop and grounds every verdict in real web sources.

The Solution

An autonomous four-step fact-checking pipeline

1
Extract

An LLM decomposes the text into atomic, checkable claims.

2
Verify

Each claim is searched against the live web, in parallel.

3
Score

Verified, outdated, hallucinated, or unverifiable — with confidence.

4
Report

A 0–100 trust score with per-claim evidence and citations.

Runs fully in demo mode with zero API keys — the same code upgrades to live search + LLM judging when keys are set.

Security & Hardening

Production-minded, even in 5 hours

✓ Rate limiting
10 requests / minute per client on the audit endpoint.
✓ Input size caps
20,000-char max, 10-char min — abuse controls.
✓ Server-only secrets
All keys read from server env; nothing hits the browser.
✓ URL-scheme validation
Source links allowed only if http/https — blocks injection.
✓ Honest gateway status
Simulated / failed results are labeled — never faked as live.
✓ Guardrail detection
Prompt-injection, credential-leak & context-overflow heuristics.

WEIGHTED AGGREGATION

Each verdict is weighted (verified 1.0 · outdated 0.4 · unverifiable 0.3 · hallucinated 0.0) and scaled by confidence to produce the 0–100 score.

Known Limitations

Honest disclosures — a ~5-hour build

Bifrost in demo mode

Gateway not wired up in time — without an LLM key, extraction + judging use a deterministic heuristic, not a true LLM.

Simulated demo results

With no keys, verdicts come from a built-in knowledge base tuned for the presets; arbitrary text gets a generic fallback.

Heuristic scorer is approximate

Relevance + keyword based; can mislabel nuanced claims. Trust score is an estimate, not proof of truth.

In-memory limiter, no persistence

Rate limiter resets per instance; audit history isn't stored (export-only JSON).

Scope caps

Up to 10 claims/audit · 20,000-char input · English-focused.

3rd-party dependency

Live mode depends on Tavily / the chosen LLM provider. Not a replacement for professional fact-checking.
